Источник: Homebox (открытый дом-инвентарь) — import-слой `backend/internal/core/services/reporting/{import.go,io_sheet.go,value_parsers.go}` + CSV-шаблоны в `.testdata/import/`. https://github.com/hay-kot/homebox
Сейчас: экспорт есть (`export/` — свой OOXML-райтер + CSV, `features/export/`), импорта таблицы нет вообще: единственный путь вкатить чужую базу — ZIP-бэкап целиком (`sync/Backup.importFromFile`). Это блокирует переезд из Excel/Google Sheets и из другого приложения.
Вариант: тот же SAF-пикер, парсер CSV/XLSX поверх существующего читателя, чистый предикат маппинга колонок + вердикт «новая / обновится по коду / дубликат», предпросмотр «+N ~M —K», применение через `Deps.items.upsertAll` (обновлённый `updated_at` = корректный LWW).
Критерий готовности: чистая функция/VM + тест(ы) (TDD RED→GREEN), `:app:testDebugUnitTest` и `:app:assembleDebug` зелёные, отдельный коммит по конвенциям AGENTS.md. Установка на телефон — вне карточки (борд T-0058).
