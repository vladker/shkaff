Многие закоммиченные правки помечены «adb install отложен — телефон не подключён» (T-029, T-043, T-050, П1.3/П1.4 и др.). Проверить `adb devices`, собрать `:app:assembleDebug` и поставить APK на SM-S928B (Android 16).

adb: C:\Users\vldkr\AppData\Local\Android\Sdk\platform-tools\adb.exe

Критерий готовности: правка в app/ или llama/ + тест(ы) на чистую логику (TDD: сначала RED), `:app:testDebugUnitTest` и `:app:assembleDebug` зелёные, `adb install -r app/build/outputs/apk/debug/app-debug.apk` на SM-S928B. Git — с `--ignore-submodules=all`; коммит `<эмодзи> <тип>: <описание>`.
