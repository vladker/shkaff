Источник: Homebox ведёт «room, value and serial number» как обязательную тройку карточки (https://gethomebox.app/); серийник — опора для гарантии и страховки.
Сейчас: `ItemEntity` хранит name/description/ean/attributes(JSON) — серийник тонет в свободном тексте, его нельзя ни найти точно, ни напечатать на этикетке. Добавить сид-атрибуты brand/model/serial (тип string) + подстановка из `AttributeEstimate`/EAN-справочника, вывод на этикетку по шаблону, поиск по серийнику через единый предикат `domain/search/ItemMatch`.
Критерий готовности: чистая функция/VM + тест(ы) (TDD RED→GREEN), `:app:testDebugUnitTest` и `:app:assembleDebug` зелёные, отдельный коммит по конвенциям AGENTS.md. Установка на телефон — вне карточки (борд T-0058).
